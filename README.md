# Quiz Competition

## Requirements
- Python 3.9+
- Flask
- flask-cors

## Install Dependencies
```bash
python -m pip install flask flask-cors
```

## Run (No Login)
```bash
python app.py
```

Open:
```
http://localhost:5000
```

## Run (Login Enabled)
```bash
python appLOCK.py
```

Open:
```
http://localhost:5000
```

## Stop Server
Press `Ctrl+C` in the terminal.
